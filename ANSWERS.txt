FOR THE CLAUDE CODE AGENT (how to pick these up)
----------------------------------------------------------------------
1. This file lives only on the claude/local-seo-gbp-improvements branch.
   Never merge it, or any other notes file, into main.
2. Work through every question whose ANSWER: is filled in and whose
   STATUS: is "open".
3. Make the site changes on a branch cut from main (not this branch),
   using the "Affects:" line as the starting point. Follow CLAUDE.md.
   Only publish what the answer actually says: don't embellish claims.
4. If an answer is unclear or contradicts something else, don't guess.
   Change STATUS to "needs clarification: <what's unclear>" and tell
   the user.
5. Answers that need no code change (e.g. who owns a login): record
   them and set STATUS to "noted".
6. After applying, set STATUS to "applied: <PR link or commit>" here,
   and update CLAUDE.md where it records the fact (e.g. phone numbers,
   hours, address).
7. Commit the updated ANSWERS.txt to this branch, then summarise to the
   user what changed and which questions are still open.
8. Once a question is fully answered and applied (or noted), move it to
   section Z (CLOSED) and prefix its STATUS with "closed.". If part of
   it is still unanswered, open a new follow-up question in section G
   for that part rather than leaving the old one half-open.
